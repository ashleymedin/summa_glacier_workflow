Tools for converting SUMMA automatic arrays to threadprivate scratch arrays sized by sizeScratch (scratch.f90),
and for checking the result on gulkana_wolverine: build.sh (fp-contract off build of a worktree), runcase.sh
(run with malloc counting), cmpdir.py (bit-identity of two output dirs), mcaller3.c (mallocs by 3-deep caller),
timeit*.sh (wall time); toscratch*.py, fixcalls.py and tidy.py do the source rewrite.
Paths point at the session scratchpad; edit S before reuse. timing*.txt are the measured results.
